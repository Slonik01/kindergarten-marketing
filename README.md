# МАРКЕТИНГ — GitHub Pages Preview

Статическая демонстрационная версия лендинга для просмотра заказчиком.

## Публичная ссылка

После первого успешного workflow сайт будет доступен по адресу:

<https://slonik01.github.io/kindergarten-marketing/>

## Что работает

- desktop- и mobile-дизайн;
- анимации;
- меню и навигация;
- открытие, заполнение и клиентская проверка формы;
- страница политики конфиденциальности.

## Ограничение демоверсии

GitHub Pages не запускает Node.js. Форма демонстрирует интерфейс и валидацию, но не отправляет данные в Telegram. Рабочий серверный вариант хранится отдельно и разворачивается на VPS.

В этом репозитории нет Telegram-токена, `.env.local`, API заявок и пользовательских данных.

## Локальный запуск

```bash
npm ci
npm run dev
```

Откройте:

<http://localhost:3000/kindergarten-marketing/>

## Проверка статической сборки

```bash
npm run check
npm run build
```

Готовые статические файлы появятся в `out/`.

## Публикация

Workflow `.github/workflows/deploy-pages.yml` автоматически проверяет, собирает и публикует сайт после каждого push в `main`.

Если Pages ещё не активирован, откройте **Settings → Pages → Build and deployment → Source** и выберите **GitHub Actions**.
